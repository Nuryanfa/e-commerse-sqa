# BAB 1 PENDAHULUAN

## 1.1 Tujuan Dokumen
Dokumen ini dibuat sebagai panduan penggunaan aplikasi e-commerce UMKM sayuran segar 
berdasarkan standar IEEE 1063-2001.

## 1.2 Ruang Lingkup Sistem
Platform e-commerce untuk distribusi sayuran segar:
- Pembeli
- Admin
- Supplier
- Kurir

Teknologi:
- Backend: Golang + Gin
- Frontend: React.js
- Database: PostgreSQL
- Payment: Midtrans
